# KITTYX organisation

The [organisation profile](profile/README.md) is the overview of the KITTYX projects.

## Documentation conventions

Each repository documents its own purpose, interfaces, requirements, build and test procedure, limitations and licence. Cross-project architecture and relationships belong in the organisation profile. Dependencies should be described only as required to use or develop the project.

Generated artefacts must remain traceable to their source and toolchain revisions. Dependency changes must preserve existing pins unless an update is explicitly intended and tested.
